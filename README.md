# OC Life

多世界 OC 生活模擬網站。

## v0.1.0

目前已完成：

- 多個互不干擾的世界
- 世界簡介、時代、主要地點、硬規則
- 每個世界獨立角色資料
- 角色身份、外貌、性格、說話方式、關係、習慣
- 「現在」頁：角色所在地、正在做什麼、心情
- 本地角色自主聊天
- 本地角色自主發動態與留言
- 手動建立聊天室與動態
- JSON 完整備份與匯入
- Gemini / OpenAI-compatible API 連接層預留
- GitHub Pages 自動部署

## 設計原則

世界硬規則 > 角色設定 > 角色關係 > 當前狀態 > 最近事件 > AI 自由發揮

不同世界的角色、聊天、狀態與動態完全隔離，不會互相污染。

## 下一步

v0.2 將把自主聊天與動態從本地模板升級為真正 AI 生成，並讓 AI 同時讀取世界規則、角色卡、關係與當前狀態。
